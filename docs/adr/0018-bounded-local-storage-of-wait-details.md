# ADR 0018: 会話の文は Mac の外に出さない。手元には限定した待ちの中身だけを保存する

- ステータス: Accepted（Amends 0005。D-218・D-214 (1)。2026-10-17）
- 日付: 2026-10-17

## Context

- ADR 0005 は「保存しない」と「送らない」を 1 つにしていた。表示の瞬間にだけ記録から読む方式（ADR 0005 の 2026-10-16 の追記）は、Claude Code が記録を 30 日（`cleanupPeriodDays`）で消すと件名と待ちの中身が消える。件名も 1 日の中で直近の指示に追従して変わり、閉じた一覧・通知・行で同じ件が別の名前になった。
- 一元管理の記録は後から消えてはいけない。流れの各段に「何を頼み、何で止まったか」を出すにも、過去の待ちを探すにも、手元に保存した文が要る。
- 「Mac の外に出さない」は信頼の芯で、変えない。手元の保存は、何を持つかを決めて小さく限れば、説明できる。

## Decision

ADR 0005 を 2 つに分ける。

1. **外には送らない（絶対）**: 会話の文（指示・AI の発言・コマンド・問い）を、LLM・作者のサーバー・中継・テレメトリのどこにも送らない。日報の AI 要約（ADR 0005 の 2026-10-03 の追記）に渡す日報からも、下の保存した中身は外す（事実から組み立て直し、`asked`・`stopped` を落とす）。SSE の `notify` には今までどおり中身を入れない。
2. **手元には限定した中身だけを保存する（許可リスト）**: 設定「待ちの中身を保存する」（`turn.store_detail`、既定オン）がオンのとき、伏せ字（ADR 0005 の 2026-10-16 の追記と同じ規則）を通した後の次の 4 つだけを SQLite に持つ。
   - (a) **自分の指示の 1 行目**（ターンごと、120 文字まで。短い返事・スラッシュコマンドだけの指示は持たない）→ `ai_instruction`。パーサが件名に使える指示の 1 行目をターンのイベントに付け（`TurnEvent.instruction`。継続状態には入れない）、シンクが伏せ字を通して書く。Claude Code の parserVersion を 4 に上げ、既存の記録から埋めるため起動時に先頭から読み直す（更新の直後の 1 回は、初回の取り込みと同じく記録の量に比例して時間がかかる。その間も画面は動き、件名は記録から読む）
   - (b) **AI の問いの文と選択肢**（問いは 2 文・300 文字まで、AskUserQuestion は問いと選択肢）→ `wait_detail`
   - (c) **許可待ちのツール名と、Claude の短い説明・コマンドの 1 行目**（Edit / Write はパス、WebFetch は host と path、MCP はツール名と引数のキー名だけ）→ `wait_detail`
   - (d) **エラーの種類**（StopFailure の hook の `error_type`）→ `wait_detail`

   (b)〜(d) は自分の番を作ったときに 1 度だけ記録から読む（デーモンの判定の後。`snapshotWaitDetails`）。

- **保存しないもの**: AI の発言の本文（問い以外）、差分、ファイルの中身、ツールの出力、記録の写し、コマンドの 2 行目以降。
- **件名**: 自分で付けた名前 → その日の最初に保存した自分の指示（日の中で変わらない。無ければ直近の保存した指示）→ ai-title → ブランチ → リポジトリ。PR の題名は 2 行目。保存がオフなら直近の指示を表示の瞬間に読む（ADR 0005 の追記のまま）。
- **読む順**: glance は DB を先に読み、無いものだけ記録から読む。保存がオフなら記録だけ。
- **書き出し**: 記録（日報・`turnlane report`・MCP の `get_daily_report`）は (a)〜(d) を含めてよい（その日の最初の指示を名前に、今止まっている待ちの中身を後ろに）。エクスポート（`turnlane export`）とバックアップは表ごと含む。どれも手元のファイルで、外には送らない。ほかの MCP のツールは含めない。
- **消す**: 設定 › データ に保存している件数と「待ちの中身を消す」（両方の表を空にする）。保存をオフにすると新しく書かない。
- **監査**: `turnlane doctor` の DB 監査は列ごとの上限（指示 120 文字、問い・説明・コマンド 300 文字、選択肢の JSON 2000 文字）で長い値を探し、保存している件数を出す（中身は出さない。`--redact` も件数だけ）。

## Consequences

- 件名が 1 日の中で変わらず、Claude Code が記録を消した後も件名と待ちの中身が残る。詳細の流れに「頼んだ: …」「止まった: …」を出せる。
- DB・WAL・バックアップ・エクスポートに伏せ字の後の指示の 1 行目とコマンドが入る。伏せ字は完全ではないので、設定の説明とデータの節に書き、オフと消す操作を用意する。
- 番兵テストは 2 つにした: 保存がオフなら ADR 0005 のまま（どこにも出ない）。オンなら番兵は決めた列（`ai_instruction.text`・`wait_detail` の文の列・確定した日報）とそれを書き出すもの（エクスポートの同じ表・MCP の日報）だけに入り、ログ・SSE・spool・AI 要約の子プロセスの stdin には出ない。
- Codex は (a) をまだ持たない（パーサが指示の 1 行目を返さない）。(b)〜(d) も glance が Codex を読まないので持たない。公開後に合わせる。
