# 段階 B (5): ⌘K コマンドパレット（M2-15）の確認手順

- 仕様: ux-mvp 6.1（コマンドパレット）、m2-api 17章（`GET /api/search`）。画像は作らず確定済みの部品で組んだ（D-037）。構成はデザイン案 (10)（検索中と空入力の2状態）を基にした
- 開き方: `⌘K`、上部バーの検索欄のクリック。もう一度 `⌘K` か `Esc` で閉じる。サイドバーのある画面で開ける（儀式・メニューバー・クイック入力の小さなウインドウでは開かない）
- キー: `↑` / `↓`（`⌃n` / `⌃p`）、`⏎` 実行、`⌘⏎` 詳細、`Tab` / `⇧Tab` でカテゴリ（All → Commands → Tasks → AI → Events → Go to）。日本語入力の変換中の `⏎` は拾わない
- `p`（時間に置く）: 画面でタスクを1件選んで `p` を押すと、パレットに空き枠の候補が出る。`1`〜`9` か `⏎` で置く（⌘Z で戻せる）。日付を入力すると別の日の候補
- 検索は本文を扱わない（タスクは題名、AI 項目は題名・リポジトリ・ブランチ・PR 番号、予定は題名だけ）

Playwright で次を通した（API の結果で確かめた）: `inbox ⏎` → `/inbox`、`week ⏎` → `/board`、`shortcuts ⏎` で一覧が開く。空入力の Recent に3件が出る。`↓` / `↑` で選択が動く。`Tab` で Commands に絞る。`wed ⏎` → その週の週ボード、`10/12 ⌘⏎` → 10/12 のデイビュー。`write article` の検索結果のタスクで `⏎` → 週ボードでそのタスクが選ばれ、もう一度開くと Selected が出る。`p` → `2` で 16:45–17:30 に時間ブロックができ、`⌘Z` で元の 14:15 に戻る。`Move to a date… ⏎` で週ボードの日付入力が開く。`Call dentist tomorrow 15m` → `Create task` で 10/3 に見積 15 分のタスク。`New task` → `Buy stamps ⏎` で Inbox に入る。`status` で `Hooks status  Claude Code off` と `Calendar status  Connected`。

## 入れ替え後に実データで見る

- デスクトップアプリ（WKWebView）で `⌘K` が開き、入力欄にすぐ文字が打てること。日本語入力で変換を確定する `⏎` で行が実行されないこと
- PR 番号・リポジトリ名・ブランチ名で過去の AI の作業が引けること。`⏎` で開く（D-059 の既定の開き先）、`⌘⏎` で詳細パネル
- `p` の候補が計画上の勤務時間（D-062）の空きから出ること
