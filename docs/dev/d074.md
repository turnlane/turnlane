# D-074: 3日ボード・週表示・見た目の改善の確認手順

仕様は ux-mvp.md 4.4.0・4.5・6章、API は m2-api.md 20章、見た目の変更点と置き換えた調整点は docs/design/README.md の「D-074」。

- **3日ボード（既定）**: 前の稼働日 25% / 今日 50% / 次の稼働日 25%（土日祝は飛ばす。金曜の次は月曜）。今日の列は 予定 15% / 自分 25% / AI 60%。長いひと続きの作業は高さに応じて題名を最大4行に折り返す。`[` / `]` と上部の `‹ ›` は1稼働日ずつ
- **週表示（計画モード）**: `w` か上部の `Week`。7日（幅に収まるだけ）。AI の時間軸のブロックは出さず、右端の稼働リボン（今日も）とヘッダの `AI 12h23m`。リボンのクリックでその日のデイビュー。`[` / `]` は1週ずつ。どちらの表示かはブラウザに覚える
- **見た目**: 予定はカレンダー色を 14% 敷く。自分のタスクは背景より明るい面と枠線（計画は強い枠線だけ、完了は面＋枠線）。AI は沈んだ面のまま
- **自分の番への対応**: デイビューと3日ボードの今日の列で、返答・レビュー等の実績を自分レーンに描かず、AI レーンの待ちの終点に `↩ 3m`（ホバーで題名と時刻、クリックでタスクのパネル）。コネクタの点線は出さない
- **閉じたもの**: YOUR TURN 帯とデイビュー左パネルの今日閉じたものは `✓ 7 closed ▸`。押すと一覧（開閉はブラウザに覚える）
- サイドバーの「Week / 週ボード」は「Board / ボード」

自動で確かめているもの（`bun run check`）: `apps/web/test/board-columns.test.ts`（列の幅、`[` / `]` の移動、ヘッダの AI 時間、今日のリボン、対応の分け方と印の位置、3日ボードのキャッシュキー）、`apps/daemon/test/board-api.test.ts` の「3日ボード」（前後の稼働日、土曜を基準にしたとき、400）、`packages/core/test/date/workdays.test.ts` の `prevWorkday`。

## 入れ替え後に実データで見る（結果を PO に返す）

1. ボードを開く → 3日ボード。今日の AI レーンで題名が読めるか（並列3本のとき）。前後の列が土日祝を飛ばしているか
2. 返答の多い日: 自分レーンに返答のブロックが出ず、AI レーンに `↩` の印が並ぶか。印が多すぎて邪魔か
3. `w` で週表示 ⇄ 3日ボード。週表示の右端のリボンを押してデイビューへ
4. ダーク・ライトで予定（色の面）・自分のタスク（明るい面と枠線）・AI（沈んだ面）が一目で分かれるか
5. YOUR TURN 帯とデイビュー左パネルの `✓ N closed ▸` を開閉
