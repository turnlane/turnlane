# D-086: 予定の面をカレンダーの色に戻す（確認手順）

仕様は ux-mvp.md 3章の項目の表と 4.4、design-system.md の Color tokens と Cards。値とコントラスト比の表は docs/design/README.md の「D-086」。

- **予定の面**: パネルの色にカレンダーの色を混ぜた不透明の面（ライト 18%・ホバー 24%、ダーク 14%・ホバー 20%）＋左の 3px のカレンダー色の線。枠線なし。D-082 のグレーの面は、ライトで勤務時間外の地と同じ色に見えたのでやめた
- **AI カードとの見分け**: AI カードは青みの面＋1px の枠線（＋左 2px の状態の線）。予定は枠線なし、左の線は 3px
- **時刻**: ライトは text-tertiary、ダークは text-secondary（`--dl-ev-meta`）
- **勤務時間の外だけにある予定**: 従来どおり面なしで、カレンダー色 25% の 1px の枠線と左の線（D-082）。左の線は 3px にそろえた

自動で確かめているもの（`bun run check`）: `apps/web/test/event-surface-tokens.test.ts`（トークンの値、CSS の規則、代表的な13色のカレンダー色の面の上の文字の比と色差）。

## ダミーデータで見る

```sh
bun run build:web
bun scripts/dev-board.ts --dense --lang ja --theme light   # デイビューは --open /day、ダークは --theme dark
```

| ファイル（`docs/dev/screens/d086/`） | 見るところ |
|---|---|
| `three-day-ja-light` / `-ja-dark` | 予定（朝会、プロダクト定例、1on1 など）がカレンダーの色の面と左の 3px の線で、パネルの上で地の色と違って見える。今日の AI レーンの AI カード（青みの面＋枠線）と見分けられる |
| `day-view-ja-light` / `-ja-dark` | 予定レーンの面と時刻（ダークは text-secondary） |

ヘッドレスの Chrome（CDP、1440×900、2倍）で撮影。`--dense` の予定はすべて dev-board の灰青（#6B8CC7）で、ライトの AI カードの面に最も近い色（ΔE 4.2）。勤務時間外だけにある予定は `--dense` のデータに無いので画像に出ていない（テストで確かめている）。

## 入れ替え後に実データで見る（結果を PO に返す）

1. ライトで、予定がパネルの上で「時間外の穴」に見えず、予定として見えるか。地（グレー）と見間違えないか
2. 青系のカレンダーの予定と AI カードが見分けられるか（枠線の有無、左の線の太さ）
3. グレーのカレンダーを使っていれば、その予定が地に埋もれていないか（色の面がほぼ無いので左の線だけが頼り）
4. ダークで、面の濃さ（14%）と時刻（text-secondary）が強すぎないか
5. 夜の予定（勤務時間外だけにある予定）が枠線だけで出て、勤務時間内の予定と区別できるか
