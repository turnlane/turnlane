# D-082: 勤務時間のパネルの確認手順

仕様は ux-mvp.md 4.4（24時間の時間軸）と 3章の項目の表、design-system.md の Color tokens と Time on the grid。確定デザインは 非公開の画像（実データの予定名を含むためリポジトリに置かない）、値と比は docs/design/README.md の「D-082」。

- **地とパネル**: 時間軸の地（勤務時間外）を沈め、勤務時間を各日の一段明るいパネル（角丸 6px・1px の枠線・列の左右 4px の余白）で浮かせる。斜線と時間外の塗りはやめた。時間軸の共通部品 `GridBackground`（`apps/web/src/board/TimeGrid.tsx`）だけで描くので、3日ボード・週表示・デイビュー・朝の計画 Step 3 がそろう。パネルの範囲は従来の勤務の窓（`workWindows`。今日は 作業の開始〜計画の終了、過ぎて作業中なら今まで、閉店していれば閉店の時刻）
- **罫線と目盛り**: 罫線は地の上で薄く、パネルの中で一段見える。目盛りのラベルは計画上の勤務時間（表示中の列のどれか）の時刻を text-secondary、それ以外を text-tertiary
- **予定**: グレーの面＋左の 2px のカレンダー色の線。勤務時間の外だけにある予定は面を塗らず、カレンダー色 25% の枠線と左の線だけ
- **ホバー**: パネルの外で「勤務時間外 · 放置に数えません」（従来どおり）
- ダークの text-tertiary を #5F636A → #686C73（パネル・予定の面・タスクの面の上で 3:1 を保つ）

自動で確かめているもの（`bun run check`）: `apps/web/test/d082.test.ts`（トークンの値、地とパネルの ΔL*、罫線、地・パネル・AI カード・タスク・予定の面の上の文字の比、AI カード・タスクの枠線とパネルの ΔL*、斜線のトークンが無いこと、パネルを描くのが TimeGrid.tsx だけ、`workBands` / `outsideWork` / `strongHour` / `strongRanges`）。

ヘッドレスの Chrome（CDP、1440×900、2倍）で撮影。`--dense` のデータには勤務時間外だけにある予定が無いので、枠線だけの予定は画像に出ていない（テストで確かめている）。

## 確定デザインとの違い

- 時間外の目盛りのラベルはデザインより濃い（デザインの値はライト 2.2:1・ダーク 2.5:1 で 3:1 に届かない）
- 予定の面は無彩色のグレー（デザインの青みのグレーはライトの AI カードの面とほぼ同じ色になる）。線にはカレンダーの色を残す
- デザインに無い要素（YOUR TURN 帯・未定・AI レーン・AI 稼働リボン・開始の境界）はそのまま。稼働リボンは列の右端（パネルの外）

## オーナーの入れ替え手順

```sh
cd ~/source/dayline
git pull               # main
bun install
bun run check
bun run build
bun run smoke
out/turnlane self-install    # デーモンと turnlane を入れ替える（マイグレーションは無し）
```

Web だけの変更なので、デーモンの入れ替えと開いているウインドウの再読み込み（⌘R）で反映される。デスクトップアプリとカレンダーヘルパは入れ替え不要。

## 入れ替え後に実データで見る（結果を PO に返す）

1. ライトとダークで、勤務時間（パネル）と時間外が一目で分かるか。パネルが薄すぎ・濃すぎないか
2. パネルの上の AI カード・自分のタスク・予定が埋もれずに読めるか（特にダークの AI カード）
3. 夜の予定（勤務時間外だけにある予定）が枠線だけで出て、勤務時間内の予定と区別できるか。カレンダーの色が線で分かるか
4. 今日のパネルが開始〜計画の終了（作業中なら今まで、閉店後は閉店の時刻まで）になっているか
