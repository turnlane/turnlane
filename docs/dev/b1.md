# 段階 B (1)(2): 週ボードの DnD・Inbox の「+ Add」・計画上の勤務時間（D-062・D-063）の確認手順

- (1) 週ボードのドラッグ＆ドロップ（ux-mvp 7章、m2-api 14章）と、Inbox の先頭の「+ Add」（ux-mvp 5章）
- (2) 空き時間（Free）を設定の「計画上の勤務時間」から出す（m2-api 9.1）。時間軸の灰色 = 勤務時間の外（D-063）。設定画面の「Working hours」と `turnlane config set work_hours.planned`

## ダミーデータで見る

```sh
bun run build:web
bun scripts/dev-board.ts --lang en --theme dark   # または --theme light
```

灰色の上のホバー（`Outside working hours · not counted as idle`）はブラウザのツールチップなので画像に写らない。自動の確認では、灰色の上で列の `title` がその文言になること・項目の上では消えることを見た。

ドラッグの操作は Playwright で次を通した（どれも API の結果で確かめた）: Unscheduled → 別の日の時間軸（ブロック作成と日付の移動）、ブロックの別の日への移動、下端の伸縮（15分スナップ）、時間軸 → 別の日の Unscheduled（ブロックを外す）、Inbox トレイ → 時間軸、時間軸 → Inbox、⌘Z（Inbox へ移したものが元の日・時刻に戻る）、空白の範囲選択 → 入力 → ⏎（タスクとブロック）、`⌫`（ブロックだけ外す）。

## 入れ替え後に実データで見る

- 週ボードを開き、未来の平日の `Free` が「10:00〜19:00 − 予定」（15分単位）になっていること（学習した 11:06〜25:57 の 14h51m ではない）
- 今日の列が「実績の開始〜19:00」まで白で、今より後が灰色になっていないこと。ダークでも灰色が見えること
- 設定 → Working hours で曜日の時刻を変えると、週ボードの白い範囲と `Free` がすぐ変わること。CLI なら `turnlane config set work_hours.planned '{"mon":{"start":"09:30","end":"18:00"}}'`（書いていない曜日は 10:00〜19:00）
- Unscheduled のタスクを時間軸へドラッグしてブロックにし、下端で伸ばし、⌘Z で戻せること。Inbox トレイ（目盛りの上端のアイコン）から日付カラムへ移せること
- カレンダーへの書き戻し（`Turnlane` カレンダー）は M3-3 なので、まだ Calendar.app には出ない
