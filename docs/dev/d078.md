# D-078: AI カードの面と勤務時間外の確認手順

仕様は ux-mvp.md 3章（項目の種類）・4.4、design-system.md の Color tokens。値とコントラスト比は docs/design/README.md の「D-078」。

- **AI カード**: 沈んだグレー（sunken）をやめ、専用の面（ライト #EEF2F7、ダーク #13161A）と 1px の枠線（#C9D2DE / #2C313A）。デイビューの左 2px の状態の線は枠線の上に描く。ホバーは枠線を一段濃く（ライトは面も #E6ECF4）、選択は 1px のアクセントのアウトライン。部品は `.dl-ai`（`apps/web/src/styles.css`）で、3日ボード・週表示・朝の計画 Step 3 の `AiRunBlock` と `N runs` のまとめ、デイビューの AI ブロックが使う
- **勤務時間外**: 塗りをやめ、背景色のまま斜線（`.dl-off`。45° の 1px を 7px 間隔、ライトは黒 5%、ダークは白 5%）。時間軸の共通部品 `GridBackground` だけで描くので、3日ボード・週表示・デイビュー・朝の計画 Step 3 がそろう。予定との重なり（`.dl-hatch`: 135°・6px・text-tertiary 35%）とは向き・間隔・濃さが違う

自動で確かめているもの（`bun run check`）: `apps/web/test/timeline-tokens.test.ts`（styles.css のトークンを読み、AI カードの面とホバーの上の text-primary / secondary ≥ 4.5、tertiary ≥ 3、面と running の青の比 ≥ 3、枠線の濃さの順、塗りのトークンが無いこと、斜線の角度・間隔・濃さ、重なりの斜線と違うこと）。

## ダミーデータで見る

```sh
bun run build:web
bun scripts/dev-board.ts --dense --lang ja --theme light   # --open /day でデイビュー
```

| ファイル（`docs/dev/screens/d078/`） | 見るところ |
|---|---|
| `three-day-ja-light` / `-ja-dark` | 今日の AI レーンのカードが青みのある面と枠線で、タスク（白い面）・予定（色の面）・背景と見分けられる。19:00 以降と 9:00 前が斜線 |
| `day-view-ja-light` / `-ja-dark` | AI ブロックの左の状態の線（許可待ちの橙・自分の番の紫）と枠線。勤務時間外の斜線 |

ヘッドレスの Chrome（CDP、1440×900、2倍）で撮影。デイビューの 15:00 付近の `放置 1h` と `放置 45m`、3日ボードの `draft pricing` と `放置 5h20m` の重なりは D-074 からある表示で、今回は変えていない。

## オーナーの入れ替え手順

```sh
cd ~/source/dayline
git pull               # main
bun install
bun run check
bun run build
bun run smoke
out/turnlane self-install    # デーモンと turnlane を入れ替える（マイグレーションは無し）
```

Web だけの変更なので、デーモンの入れ替えと開いているウインドウの再読み込み（⌘R）で反映される。デスクトップアプリとカレンダーヘルパは入れ替え不要。

## 入れ替え後に実データで見る（結果を PO に返す）

1. ライトで、AI カードがカードとして見えるか（勤務時間外・タスク・予定と混同しないか）。running の青と見間違えないか
2. 斜線が薄すぎ・濃すぎないか（ライトとダーク）。予定との重なりの斜線と見分けられるか
3. AI カードのホバー・選択が分かるか
