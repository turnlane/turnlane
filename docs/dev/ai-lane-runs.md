# AI レーンをひと続きの作業で描く（D-061、W7）の確認手順

週ボードの今日の AI レーンは、ターンごとではなく AI 項目ごとのひと続きの作業（間隔30分未満のターン）を1ブロックで描く。
5分未満の完了ブロックが重なって並ぶときは `✓ N runs · 3m` にまとめる。規則は ux-mvp 4.4、配置は `packages/core/src/layout/ai-lane.ts`。
あわせて、既定ブランチの session カードもリポジトリを持つようにした（「(no repo)」は git 管理外だけ。phase0-plan 3.3 のグルーピング 3）。

## ダミーデータで見る

```sh
bun run build:web
bun scripts/dev-board.ts --lang en --theme dark
```

ダミーデータに次を足した:
- `notes` リポジトリの `main` で続けている「Plan the Q4 roadmap」: 10:02 からの 12 分のターンのあと、タスク通知で始まる 40 秒のターンが 4〜9 分おきに 11 回（1ブロック `19m` になる）
- 11:40 / 11:43 / 11:47 に別々の AI 項目の 1 分ほどの完了（`✓ 3 runs · 3m` にまとまる）
