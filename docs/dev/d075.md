# D-075: 常用フィードバックの確認手順

仕様は ux-mvp.md 4.4.0・4.4（待ちの線）・4.5・6章・6.1、desktop-shell.md 2.5。見た目の変更点とライトのコントラスト比は docs/design/README.md の「D-075」。

- **3日ボードの今日の列**: Plan（予定・自分）35% / AI 65% の2レーン。予定とタスクの重なりは W5（予定の中で始まるタスクは題名の下に入れ子、入らなければ列を分ける）。デイビューは 15 / 25 / 60 の3レーンのまま
- **`↩` の廃止**: AI レーンで目立たせる待ち線は開いている待ち（待ち中・放置中）だけ。閉じた待ちは 1px 灰色点線と終わりの小さな点。点と線のホバーで `13:40 に返答 · 3m`（返答のタスクが無い閉じ方は `13:38 に終了`、デイビューは `13:38 に解決` など）、クリックで返答のタスクのパネル（返答が無ければ AI 詳細パネル）。デイビューの閉じた待ちの放置区間は帯（4%）とラベル（三次テキスト）を残す
- **ビューのキー**: `⌘1` 3日 / `⌘2` 週 / `⌘3` 日。`g b` ボード（最後に使った表示）/ `g w` 週 / `g d` 日（今日）/ `g y` 自分の番（`g q` も可）/ `g i` Inbox / `g r` 日報 / `g p` 今日を計画する / `g s` 設定。`w` は残る。上部の `3日 / 週 / 日` のツールチップ、⌘K の Go to、`?` の一覧に出る。デスクトップアプリは「View」メニューに `3 Days ⌘1` / `Week ⌘2` / `Day ⌘3`
- **ライトのコントラスト**: 面・枠線・二次/三次テキストを一段濃く、予定の色の面 20%、AI の沈んだ面を背景・勤務時間外と区別。ダークは変えない

自動で確かめているもの（`bun run check`）: `apps/web/test/board-views.test.ts`（レーンの割合、閉じた待ちと返答の結び付け、ホバーの文、点の位置、⌘1〜⌘3 と g の2打鍵、重複しないこと、ツールチップの表記、⌘K の行）。`bun run check:desktop` の `windows::tests::maps_view_menu_items`。

## オーナーの入れ替え手順

```sh
cd ~/source/dayline
git pull               # main
bun install
bun run check
bun run build
bun run smoke
bun run build:desktop  # View メニューの ⌘1〜⌘3（Rust の変更）を入れる。署名は docs/dev/desktop.md の 1 章
out/turnlane self-install    # デーモンと turnlane を入れ替え、out/Turnlane.app も ~/Applications に置き直す（マイグレーションは無し）
```

Web の変更（レーン・点・キー・ライト）はデーモンの入れ替えと開いているウインドウの再読み込み（⌘R）で反映される。デスクトップアプリを入れ替えない間は、アプリの中では ⌘1〜⌘3 がメニューに無いので効かない（WKWebView に keydown として届くかは未確認）。`g b` / `g w` / `g d` と上部の切り替えは使える。カレンダーヘルパは入れ替え不要。

## 入れ替え後に実データで見る（結果を PO に返す）

1. 3日ボードの今日の AI レーンで題名が読めるか（並列3本のとき）。Plan レーンで予定とタスクが読めるか（重なる時間帯）
2. 返答の多い日に、閉じた待ちの点が邪魔でないか。点のホバーで `13:40 に返答 · 3m`、クリックで返答のタスクのパネル
3. ⌘1 / ⌘2 / ⌘3 と g の2打鍵で行き来できるか。`?` の一覧と ⌘K に出ているか
4. ライトで、文字・枠線・予定の色・AI の面・勤務時間外が見分けられるか（ダークは変わっていないこと）
