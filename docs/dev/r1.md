# r1: ⏎ の統一・日本語の仕上げ・設定画面の残り・儀式の抜け方・詳細パネルの確認手順

- ⏎ の統一（D-067。ux-mvp 6章のキー表）: AI カードと自分の番は `⏎` で外部の既定の開き先（D-059）、`→` / `⌘⏎` で詳細パネル。週ボード・デイビュー・YOUR TURN 帯・キュー・⌘K・メニューバーのポップオーバーで同じ。ポップオーバーの `→` / `⌘⏎` は main ウインドウを `/board?panel=<id>` で出して AI 詳細パネルを開く。儀式の画面の `⌘⏎` は従来どおり次へ
- 日本語の辞書（M2-20）: ja の欠けを0にした。欠けがあると `apps/web/test/i18n.test.ts` が失敗する
- 設定画面の残り（M2-9。ux-mvp 2章）: 取り込み元（プロファイルごとに 取り込む / 除外、健全性と hooks の状態、除外する glob、再検出。D-017）、祝日（自動 / 選ぶ / なし と「Holidays from」のまとめ表示。D-057 (2)）、日付の区切り、カレンダーの役割（表示する / 無視する）、自分の番（種類ごとのオン・オフ、猶予、質問の期限、git 管理外の編集の期限 = 24時間ルール）、セッションの題名の保存（プライバシー）。日報の AI 要約は M4-6、プロジェクトとリポジトリの対応は残り
- 画面のスクロールと折り返し（D-069 (1)(2)）: サイドバーのある画面は内容が長ければ縦にスクロールする。設定の各行は説明文の側が折り返し、セグメント・ボタンは折り返さない
- 儀式（D-069 (3)(4)。ux-mvp 8章）: `Esc` か上部右の `Later ×` で週ボードへ戻る（完了は記録しない）。一覧と決めた内容は端末ごとにその日だけ覚え、入り直すと未処理の行から。朝の計画を終えた後は Step 3 から開き `Done` で戻るだけ。閉店後のシャットダウンは日報から開き、本文と Note を直して `Update ⌘⏎`（持ち越し・閉店時刻・通知の停止はそのまま）
- タスクと予定の詳細パネル（S6b。D-070。ux-mvp 4.12）: 自分のタスクはクリックか `⏎`（`→` / `⌘⏎` も）、予定はクリックで開く。⌘K の結果からも開く

## 入れ替え後に実データで見る

- 週ボードとデイビューで AI カードを選んで `⏎` → セッション・PR が開く（パネルは開かない）。`→` と `⌘⏎` で AI 詳細パネル
- メニューバーのポップオーバーで行を選んで `→` → main ウインドウが出て AI 詳細パネルが開く（デスクトップアプリ）
- 設定画面がデスクトップアプリ（WKWebView）でも最後までスクロールできること。「閉店後の許可待ち」のオフ / オンが横に並ぶこと
- 設定の取り込み元で、別アカウントのプロファイルを「除外」にすると、そのプロファイルのセッションが増えなくなること（戻すと再開する）
- 朝の計画の途中で `Esc` → 週ボードに「今日を計画する」の帯が残る → 入り直すと未処理の行から
- 閉店後にサイドバーの「日報」か ⌘K の Close the day → 日報を直して `Update` → 日報の画面に反映。通知は止まったまま
- 実際の予定をクリック → 予定のパネル。`カレンダーで開く` を押すと、初回だけ macOS が「turnlaned が Calendar を制御する」許可を聞く。許可するとその予定が Calendar.app に出る。許可しない・見つからないときは Calendar.app が開くだけ
