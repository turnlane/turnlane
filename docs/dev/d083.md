# D-083: 設定画面の節分けの確認手順

仕様は ux-mvp.md 4.14（設定画面の節）と 6.2（キーボードの節）、desktop-shell.md 3.3。節と項目の目録は `apps/web/src/routes/settings-index.ts`。

- **節**: 一般 / 時間と稼働日 / カレンダー / AI の取り込み / 自分の番 / 通知 / 朝と夕方 / 開く / プロジェクト / キーボード / デスクトップアプリ / データ。1度に1つの節だけを出し、`/settings#<節>` で開く（ハッシュが無い・知らない値は一般）
- **目次**: 左の列（200px、スクロールしても残る）。設定画面の幅が 720px 未満ならプルダウン
- **検索**: 項目名と説明（表示中の言語と英語）で絞る。結果を選ぶか `⏎` で節を開いて項目へスクロールし、1.6秒強調。`Esc` で消す
- **リンク**: `?` の一覧・⌘K の「キーボードショートカットを変更」→ `#keyboard`、⌘K の hooks → `#ai`、カレンダー → `#calendar`、メニューバーの `⌥⇧Space is in use · Change` → `#keyboard`（Rust の変更）
- **キーボードの節**: D-080 のアコーディオン（既定は閉じる）を外した。節を目次から直接開けるので、閉じておく理由が無くなった
- **項目の移動**: 「セッションの題名を保存」は自分の番の節から AI の取り込みへ。デスクトップアプリの通知の行は通知の節の「デスクトップの通知」へ（アプリが起動していなければ「起動していません」と出す。以前は行ごと隠れていた）。ブラウザ通知の見出しは節の名前と重なるので「通知」→「ブラウザ通知」
- **足した説明だけの項目**（値を持たず、操作は CLI）: hooks（`turnlane hooks install`）、持ち越し、デスクトップアプリの状態（起動中 · 版）とログイン時に起動（`turnlane self-install`）、データのバックアップ（`turnlane backup`）・書き出し（`turnlane export --json`）・プライバシー
- 勤務時間の説明文を D-082 に合わせた（「斜線」→「勤務時間のパネル」）

自動で確かめているもの（`bun run check`）: `apps/web/test/settings.test.ts`（12節の順と名前、D-083 より前の項目の漏れの一覧、目録と画面の `data-setting` の一致、節の中身が既存の部品をすべて置くこと、キーボードの節にアコーディオンが無いこと、ハッシュから節、`?` の一覧・メニューバー・⌘K のリンク先、検索）。`bun run check:desktop`（tray.rs の変更）。

## オーナーの入れ替え手順

```sh
cd ~/source/dayline
git pull               # main
bun install
bun run check
bun run build
bun run smoke
out/turnlane self-install    # デーモンと turnlane を入れ替える（マイグレーションは無し）
```

設定画面は Web だけの変更なので、デーモンの入れ替えと開いているウインドウの再読み込み（⌘R）で反映される。メニューバーの `⌥⇧Space is in use · Change` からキーボードの節へ直接飛ぶのはデスクトップアプリの変更（`bun run build:desktop` のあと `out/turnlane self-install`。署名は docs/dev/desktop.md の 1 章）。入れ替えなくても設定画面（一般の節）は開く。カレンダーヘルパは入れ替え不要。

## 入れ替え後に実データで見る（結果を PO に返す）

1. 目次から各節を開いて、前にあった項目が見つかるか（どこにあるか迷った項目があれば教えてください）
2. 検索で項目名（「猶予」「題名」「祝日」「バックアップ」など）を入れて、該当の節に飛んで強調されるか
3. `?` の一覧の「設定 › キーボード で変更」と ⌘K の「キーボードショートカットを変更」でキーボードの節が開くか
4. ウインドウを狭くしたときに目次がプルダウンになるか
