# S10: スリープさせない（caffeinate -i）を一晩保持して朝まで起きているか

- 状態: **一部実施**（2026-10-14、一晩。2・3 は確認済み、外部ディスプレイありでふたを閉じた状態の 4 も確認。1 は sleep 0 の Mac のため判定できず、既定の電源の設定の Mac で残す）。利用者の Mac の電源の状態（電源・ふた・ロック・ディスプレイのスリープ）が要るので、利用者が流す。結果は下の「結果」の表に書く
- 関連: [m2-api.md](../spec/m2-api.md) 28 章（`power.keepAwake`・`power.state()`）、ADR 0013（在席は入力の無操作時間だけで見る）
- 目的: 拡張が長い処理の間に `power.keepAwake` を保持したとき（本体は `caffeinate -i -w <デーモンの pid>`。ディスプレイは止めない）、人がいない夜のあいだ Mac が起きているか、在席に見えないか、ふたを閉じたらどうなるかを確かめる

## 結果を待たずに入れたもの

- `power.keepAwake` は `-i` だけ（`-d`・`-u` は使わない。ディスプレイを点けたままにしたり、入力があったように見せたりしないため。ADR 0013）
- `power.state()` は `pmset -g batt` と `ioreg -r -k AppleClamshellState -d 1` を読むだけ。電源の設定は変えない
- ふたを閉じた（外部ディスプレイなし）ときはスリープを止められない前提。拡張は判定の間隔が大きく空いたら「スリープしていた区間」として記録する

## 確かめること

| | 内容 | 見る値 |
|---|---|---|
| 1 | ふたを開けたまま、ディスプレイのスリープ、その後の画面のロックで、朝まで起きているか | `sleptGaps`（2分を超えた空き）、`maxGapSec` |
| 2 | 保持が `pmset -g assertions` に出ているか（この caffeinate の PreventUserIdleSystemSleep） | `holdingAlways`・`holdingRatio` |
| 3 | 在席に見えないか（最後の入力からの経過が増え続ける・UserIsActive が 0） | `shortIdleAfterLock`（0 がよい）、`userIsActiveSamples`、`maxIdleSec` |
| 4 | ふたを閉じたときの判定の空き | ふたを閉じた回の `sleptGaps` |

利用者の Mac がシステムのスリープ「しない」（`pmset -g` の `sleep 0`）なら、1 は caffeinate が無くても起きているので判定できない。そのときは 2・3・4 だけを確かめ、1 はテスト用の macOS ユーザー（電源の設定が既定）か、別の Mac で確かめる（利用者の電源の設定は変えない）。

## 手順

前提: 本体のリポジトリ（または作業用の worktree）で `bun install` 済み。電源の設定は変えない（読むだけ）。

0. 手順の確かめ（5秒で終わる）

   ```sh
   bun scripts/spike-s10-keep-awake.ts --dry-run
   ```

   3行の記録と要約が出て、`"holdingAlways": true` なら準備はできている

1. 一晩（ふたを開けたまま）: 電源につなぎ、寝る前に流す。ディスプレイが消えるのを待ち、⌃⌘Q で画面をロックして離れる。朝、ロックを外して Ctrl-C（8時間たてば自分で終わる）

   ```sh
   bun scripts/spike-s10-keep-awake.ts --hours 8
   ```

2. ふたを閉じたとき（30分）: 外部ディスプレイを外し、電源につないだまま流して、すぐにふたを閉じる。20分ほどしたら開けてロックを外し、終わるのを待つ

   ```sh
   bun scripts/spike-s10-keep-awake.ts --hours 0.5
   ```

3. 終わると画面に要約の JSON が出て、`out/s10-results.jsonl` に1行足される（1回ごとの記録は `out/s10-samples-<時刻>.jsonl`）。要約の JSON を PO に渡す。中身は macOS の版・電源の設定の値・時刻（時:分）・回数だけで、パス・アプリの名前は入らない

## 見る点

- 1: `sleptGaps` が空で `maxGapSec` が間隔（30秒）の数倍以内なら、朝まで起きていた。空きがあれば、その時刻と長さ（ディスプレイのスリープ・ロックの時刻と比べる）
- 2: `holdingAlways: true`
- 3: `shortIdleAfterLock: 0` かつ `userIsActiveSamples: 0` なら、保持しても在席には見えない（本体の在席は最後の入力からの経過で見る）
- 4: ふたを閉じていた間が `sleptGaps` に1つの空きとして出る（止められない前提どおり）。`lidClosedSamples` は閉じていても起きていた記録の数（外部ディスプレイがあると増える）
- 駄目なとき: ディスプレイのスリープ・ロックで眠ってしまうなら、電源につながっているときだけ `-s` を足す案を PO に上げる
